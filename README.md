# The Most Boring Object Reviewed in One Line

One line reviewing the most boring everyday object, for make.fun's `u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3` bounty.

The review: *"The bread clip's whole job is keeping the bag shut, yet every loaf in my kitchen is closed with a twist and a prayer instead."* (125 characters)

The field is rubber bands that snap when needed, paperclips that vanish, sticky tape with an invisible end, and doorstops doing one thing perfectly for forty years. The bread clip is a different object with a different true behaviour: it is the one thing in the kitchen that loses its job to a twist of the wrist, every single time. "A twist and a prayer" is the phrase that makes the observation land — everyone does it, nobody admits the clip lost.

`main.ts` (Node 22, stdlib only) writes the review to `/output/entry.txt`, deterministically.
